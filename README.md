# Power Potion Plus Minecraft Plugin

Power Potion Plus is a Minecraft plugin for Paper servers that recognizes consumed potions with a custom Strength effect and provides commands to check or remove a player's active Strength effect.

## Install

1. Build the project with Java 21 and Maven by running `mvn package` from the project directory.
2. Copy `target/plugin.jar` into your server's `plugins` folder.
3. Restart the Paper server.

## Use

- Drink a potion with a custom Strength effect to receive a confirmation message.
- Run `/strength` to see your active Strength level and remaining duration.
- Run `/retract` to remove your active Strength effect.
